تمام يا معلم، التوضيح ده مهم جدًا، وكده **الـ Gap دي اتقفلت**. 👌

يعني عندنا المنطق:

```text
Homepage Mode = Exhibition
        ↓
exhibition_id = X
        ↓
نقرأ end_date من المعرض X
        ↓
هل تاريخ المعرض انتهى؟
   │
   ├── لا → Exhibition Landing
   │
   └── نعم → Company Homepage
```

وبالتالي **مش محتاجين `landing_end_date`** طالما القرار المقصود هو أن الـ Landing Page تنتهي تلقائيًا بانتهاء المعرض نفسه. وهنحافظ على المنطق الحالي بدل ما نضيف حقل جديد بدون داعي.

# المرحلة 0 — حماية المشروع 🔐

دي أول حاجة نعملها قبل أي Firebase code.

## 1. `.env.local`

هنحط الـ Secrets في:

```text
.env.local
```

وده الملف اللي **ما يترفعش على GitHub**.

مثلاً:

```env
FIREBASE_PROJECT_ID=...
FIREBASE_CLIENT_EMAIL=...
FIREBASE_PRIVATE_KEY="..."
```

ولو احتجنا Cloudinary أو أي API Secret بعدين:

```env
CLOUDINARY_API_SECRET=...
```

### مهم جدًا

مش هنحط:

```text
private key
client email
API secret
service account
```

داخل:

```text
components/
app/
public/
GitHub
```

---

# 2. `.gitignore`

نتأكد إن عندنا:

```gitignore
.env
.env.local
.env.*.local
```

وبالتالي لو عملت:

```bash
git add .
```

الـ secrets مش هتدخل Git.

---

# 3. `.env.example`

دي حركة مهمة جدًا عشان لو وقفت المشروع 6 شهور ورجعت له تعرف محتاج إيه.

نعمل:

```text
.env.example
```

مثلاً:

```env
FIREBASE_PROJECT_ID=
FIREBASE_CLIENT_EMAIL=
FIREBASE_PRIVATE_KEY=
```

**لكن بدون أي قيم حقيقية.**

يعني:

```text
.env.local       ← الأسرار الحقيقية
.env.example     ← أسماء المتغيرات فقط
```

---

# 4. لو رفعت المشروع GitHub

الـ GitHub يحتوي:

```text
.env.example
```

ولا يحتوي:

```text
.env.local
```

ولو بالغلط الـ Secret اتعمل له commit في أي وقت، مش مجرد نمسح الملف ونقول خلاص؛ لازم **نغيّر/نلغي الـ credential نفسه**.

# ⚠️ نقطة أمنية مهمة جدًا

بما إننا هنستخدم **Firebase Admin SDK**:

أي متغير فيه:

```text
PRIVATE_KEY
CLIENT_EMAIL
SERVICE_ACCOUNT
SECRET
```

لازم يظل **Server Only**.

ومش هنستخدمه داخل:

```text
"use client"
```

ولا نمرره للـ browser.

أما لو احتجنا لاحقًا Firebase Client SDK في جزء معين، هنحدد بالضبط إيه الـ public config وإيه الـ secret قبل استخدامه.
